Esta descarga es para computadoras con Windows. Abre esta misma página en la computadora de la farmacia, o copia el enlace y mándatelo.

Descargar para Windows

Instalador con firma digital. Windows muestra el nombre del editor al instalarlo. Las primeras semanas de una versión aún puede aparecer el aviso azul de abajo; es normal.

Versión de piloto, sin firma digital. Al abrir el instalador, Windows muestra el aviso azul “Windows protegió su PC”. Abajo se ve cómo continuar.

Instalar

  1. Revisa la fecha, hora y zona horaria de la computadora.
  2. Abre el instalador descargado (queda en la carpeta Descargas). Se instala solo para tu usuario de Windows: no pide administrador y tarda cerca de un minuto.
  3. El instalador se cierra solo al terminar. Abre MedikApp Caja desde el escritorio o el menú Inicio.
  4. En la app del dueño: Más › Cajas › Agregar caja, y escribe el código de 6 letras en la caja.
  5. Elige la sucursal y el número de caja. Cuando el dueño la apruebe, llegan los usuarios y el catálogo solos.

Si aparece el aviso azul de Windows

Descárgalo solo desde esta página. Si el aviso no trae “Más información”, la computadora tiene un bloqueo más estricto: avísanos antes de cambiar nada.

Requisitos

  • Windows 10 (22H2) o Windows 11, de 64 bits.
  • 4 GB de memoria o más, 500 MB libres en disco y pantalla de 1366 × 768 o mayor.
  • Internet para configurarla; después vende también sin internet (solo efectivo).
  • Impresora de tickets USB o de red y lector de códigos USB (opcionales).

Actualizar

La caja busca versiones nuevas por su cuenta. Cuando hay una, la descarga y la instala sola en la pantalla de PIN, sin venta en curso, o al cerrarla; después se vuelve a abrir. No hay que hacer nada.

Cuando haya una versión nueva, la caja le avisa al administrador. Descárgala aquí e instálala encima, con la caja cerrada.

Al actualizar o reinstalar, las ventas, usuarios y configuración se conservan.

Si algo falla

  • No abre o se cierra: reinicia la computadora y vuelve a abrirla. Si sigue, instala esta versión encima.
  • No se une a la tienda: revisa el internet y la fecha y hora de la computadora; el código de 6 letras dura pocos minutos.
  • Para pedir ayuda: en la caja, Admin › Sistema muestra la versión y el resumen de errores para mandárnoslo.
